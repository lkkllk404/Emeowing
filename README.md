# Emeowing

一个完全在浏览器本地运行的 UTF-8 喵文转换器。

它把 UTF-8 字节从高位到低位每 2 bit 映射成一个符号：

| bit  | 符号 | Unicode        |
| ---- | ---- | -------------- |
| `00` | 喵   | U+55B5         |
| `01` | 咪   | U+54AA         |
| `10` | ！   | U+FF01（全角） |
| `11` | ～   | U+FF5E（全角） |

## 格式

v1 编码结果固定以 `喵咪` 开头，其中第一个符号是格式标识，第二个符号表示版本 1。格式头之后，每个 UTF-8 字节对应四个喵文符号，不使用填充。

例如：

```text
A → 喵咪 咪喵喵咪
中 → 喵咪 ～！咪喵 ！～！喵 ！！～咪
```

示例中的空格只用于展示，实际输出不含空格。解码器会忽略整体首尾空白，但严格拒绝正文中的空白、ASCII `!`/`~`、非法长度和非法 UTF-8。

每 `n` 个原始 UTF-8 字节会产生 `2 + 4n` 个 Unicode 符号。由于这里的四个符号本身都占 3 个 UTF-8 字节，保存为 UTF-8 时占用 `6 + 12n` 字节。

## 开发

要求 Node.js 22.12 或更高版本，以及项目锁定的 pnpm 11。

```bash
corepack enable pnpm
pnpm install
pnpm dev
```

常用命令：

```bash
pnpm type-check
pnpm test
pnpm lint
pnpm format:check
pnpm build
```

生产构建输出到 `dist/`。Vite 使用相对资源路径，可将该目录部署到任意静态站点根路径或子路径。

## 隐私

应用没有后端、统计、外部字体或网络请求。输入文本不会离开当前浏览器页面，也不会写入本地存储。
